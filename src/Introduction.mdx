# JustForInterviews DS

Ten hand-written React components, one at a time, each chosen for the difficulty it forces you to solve.
Use the toolbar to switch **theme** (light / dark) and **locale** (English / Español). The **Accessibility**
panel runs axe on every story.

Specs live in `docs/specs/`; each component gets its stories next to its code
(`src/components/<Component>/<Component>.stories.tsx`).

# JustForInterviews DS — Español

Diez componentes React hechos a mano, uno por vez, cada uno elegido por la dificultad que obliga a resolver.
